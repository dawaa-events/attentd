# نظام دعوة لتأكيد الحضور

مشروع عربي متجاوب مع الهاتف، جاهز للرفع إلى GitHub والنشر على Vercel أو Cloudflare أو أي منصة تدعم Next.js، ويستخدم Supabase لحفظ بيانات الحضور وتسجيل دخول العميل.

## الصفحات

- `/` صفحة عامة للمعازيم: الاسم، عدد الحضور، رقم الهاتف، وتأكيد الحضور.
- `/client/login` تسجيل دخول العميل.
- `/client/dashboard` قائمة المؤكدين، الإحصائيات، البحث، ورابط إرسال البطاقة عبر واتساب.

## 1. تجهيز Supabase

1. أنشئ مشروعاً جديداً في Supabase.
2. افتح SQL Editor وشغّل محتوى الملف `supabase/schema.sql`.
3. من Authentication > Users أنشئ حساب العميل بالبريد الإلكتروني وكلمة المرور.
4. من Project Settings > API انسخ Project URL و`anon public key`.

## 2. الإعداد محلياً

انسخ `.env.example` إلى `.env.local` ثم ضع بيانات Supabase وعدّل اسم المناسبة والتاريخ والتعليمات.

```bash
npm install
npm run dev
```

## 3. الرفع إلى GitHub

أنشئ مستودعاً جديداً ثم ارفع ملفات المشروع. لا ترفع ملف `.env.local`.

## 4. النشر

اربط مستودع GitHub بمنصة النشر، ثم أضف متغيرات البيئة الموجودة في `.env.example` داخل إعدادات المشروع. أمر البناء هو `npm run build`.

## تخصيص رسالة واتساب

عدّل قيمة `NEXT_PUBLIC_CARD_MESSAGE`. النظام يضيف اسم الضيفة تلقائياً قبل التعليمات ويفتح المحادثة على رقمها.

## الأمان

- إدخال الحضور متاح للعامة، لكن قراءة القائمة متاحة فقط للمستخدمين المسجلين في Supabase.
- جلسة العميل محفوظة في Cookie آمنة لا يمكن لسكريبتات المتصفح قراءتها.
- رقم الهاتف لا يتكرر في القائمة.
